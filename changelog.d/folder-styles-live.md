- Folders now come in six looks (frosted white, coloured glass, papers peeking, stamp and clip, app icons, dark frosted) in Projects, Docs and Learn. Each folder gets one at random from its id, so neighbours differ and a folder never changes between visits. You can pick the look for a project in its right-click menu (Folder style…) or its edit sheet, or go back to Auto. The badge, status pill, "Updated" and app icons on a folder come from real data (open and due-today tasks, last change, the task apps the project syncs with) and are left out when there is none. Docs folders wear their project's look. The project API and the MCP `needt_update_project` take `folderStyle` (1 to 6, or null for Auto), and `GET /api/projects` also lists `connectedApps`. Additive migration: `Project.folderStyle`.
