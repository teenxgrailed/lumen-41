- Task rows show the due date as a chip, in the destructive colour once the
  task is overdue.
- A new task no longer gets a priority or a reminder you did not ask for. Set
  them yourself, or write them in the quick-add line.
- In Docs, Escape on the "/" menu removes the "/" it opened with, so no stray
  slash is saved. A new doc you leave without typing goes to Trash instead of
  staying behind as an empty "Untitled".
- Keyboard hints read Ctrl, Shift and Alt on Windows and Linux instead of the
  Mac symbols.
- Settings no longer lists the Mac-only Desktop tabs (App, Island, Widgets,
  Siri & Shortcuts) in the web app. They stay in the Mac app.
- The project colour swatches have real names (Blue, Amber, Green, Red, Grey)
  for screen readers and tooltips.
