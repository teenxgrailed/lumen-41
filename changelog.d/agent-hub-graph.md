- Agent tasks can depend on each other. An agent can say one task blocks
  another, and a task that waits on an unfinished one is not offered or
  claimable until it is done or cancelled. Agents get a ready queue and a
  single "next" pick, can create a plan (a parent task with ordered steps) in
  one call, and can give done-criteria as a checklist answered item by item.
  The Agents screen shows links, the checklist, how many tokens, dollars and
  minutes a task used, and flags a task held for over four hours with no
  update. Ask can link tasks and make plans too.
