- Chrome extension 0.2.0: YouTube cleanup that works with no token and no
  Needt account. Switches for Shorts (also /shorts/ links), the home feed,
  recommendations beside the video, end cards, comments and autoplay, plus
  channel and title-word block lists (names, @handles or /regex/) that remove
  matching videos from the feed, search and sidebar. The popup shows the
  switches first and no longer shows an error without a token. The focus-block
  goal filter keeps working on top when a token is set.
