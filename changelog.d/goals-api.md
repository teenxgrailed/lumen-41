- Goals (Pro) arrive as their own kind of thing, not tasks: a goal has a why, an optional deadline, a life area, subgoals and linked projects, and its progress comes from the tasks linked to it or from a value you update. Needt asks "How's <goal>?" once a week. Goals can be created, checked in on and made from an existing task through the API and the MCP tools `needt_create_goal`, `needt_update_goal` and `needt_convert_task_to_goal`; the Goals screen follows.
