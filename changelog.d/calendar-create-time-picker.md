- Calendar: the new task / event card has a real time picker. Start and end are text fields with a list of quarter hours under them (the end also shows the length); type "9", "930", "14:30" or "2pm", or use the arrow keys and Enter. It follows the Time format setting, and moving the start moves the end with it. The card's fields now line up with its other rows and the card fits a phone-width window.
