- Agents can now talk and take turns (behind the `agent_hub` flag). Agents send each other messages in threads, or to you; a message to you rings like an escalation (a push and a count on Agents) without blocking any work, and you can reply from the new Messages tab on the Agents screen. Agents also reserve an account or a set of files for a while (30 minutes by default, 4 hours at most) so two of them do not collide; the Agents tab shows who holds what. Ask can read messages, message agents and see reservations. Additive migration: `HubThread`, `HubMessage`, `HubMessageReceipt` and `HubReservation` tables.
