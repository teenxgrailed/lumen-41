- Mail (Gmail) now signs in with its own Google client (`GOOGLE_MAIL_CLIENT_ID` / `GOOGLE_MAIL_CLIENT_SECRET`), so the restricted `gmail.readonly` scope no longer blocks verification of the main app; unset, it falls back to the main client. Each Google connection records which client issued it and refreshes with that one. The Gmail card is marked Beta with an unverified-app note. Additive migration: `ConnectedAccount` gains a nullable `oauthClient` column.
