- Server side of App Store purchases for the iOS and Mac apps, behind the `apple_iap` flag: an account token for StoreKit, verified StoreKit 2 transactions and App Store Server Notifications V2, and Pro or Lifetime written into the same plan the web reads. Lifetime seats count App Store and web buyers together. An App Store plan shows "Manage in App Store" in Settings, the deletion screen says the App Store subscription keeps billing until it is cancelled there, and the web checkout refuses while one is live. App Store Pro always ends with its paid period; Sandbox purchases (App Review, listed testers) count only as a day of Pro. Additive migration: `User.appleAppAccountToken`, Apple columns and a `provider` on `Subscription`, and an `AppleNotificationReceipt` table.
