- Agents: you can cap what each agent takes from the hub, on the Agents screen (open an agent). Set how many items it may hold at once, how many new claims it may make per day, how many items its inbox shows (best first), and whether it takes items flagged large. At a cap the agent is told to retry later and the rest stay queued. Agents without limits behave as before, and an agent cannot change its own limits.
