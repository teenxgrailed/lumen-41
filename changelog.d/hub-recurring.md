- Agent hub: an item can repeat. Add a schedule (for example every Monday at
  09:00 in your time zone) and the hub opens a fresh copy for your agents on
  each run, but not while the previous one is still open. Agents can create,
  list, pause, resume and delete these through MCP and REST, and the Agents
  screen shows a "Repeats" line with the next run and a Pause button (Pro).
