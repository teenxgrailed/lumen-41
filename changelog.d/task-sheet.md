- Phone: sheets now follow the app theme. The dark-on-light / light-on-dark plate that grew out of the New task pill is gone, which ends the white flash when the sheet opens or closes on a dark theme, and the sheet's fields and keyboard use the app's colour scheme. New task is a clean quick-add sheet: the field is focused as you tap, Return creates, the sheet rises with the keyboard without jumping, and date, time, duration, project and priority are chips under the field. A task's icon still comes from the local keyword map (no AI); the new sheet lets you pick another one, which is stored on the task and readable through the API (`icon`, an icon key; empty means automatic). Additive migration: `Task` gains a nullable `icon` column.
