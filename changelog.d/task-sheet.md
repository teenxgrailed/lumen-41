- Phone: sheets now follow the app theme. The dark-on-light / light-on-dark plate that grew out of the New task pill is gone, which ends the white flash when the sheet opens or closes on a dark theme, and the sheet's fields and keyboard use the app's colour scheme. New task now works like the desktop composer: the field is focused as you tap, the words it understands (day, time, length, project, priority, deadline, subtasks after a slash) are marked inside the sentence, the sheet rises with the keyboard without jumping, and When, Duration, Project, Priority and More (Deadline, Notes, Subtasks) are rows in the task sheet's own layout. Return adds and keeps the sheet open for the next one; Add adds and closes. A task's icon still comes from the local keyword map (no AI); the new sheet lets you pick another one, which is stored on the task and readable through the API (`icon`, an icon key; empty means automatic). Additive migration: `Task` gains a nullable `icon` column.
