- Phone: the numbers for a day now agree. Home's "x of y tasks" counts tasks done of the tasks on the day (it showed the plan's limit, so 5 tasks with 2 done read "5 of 5"), the greeting, the focus total and the time-left card read the same set of tasks, and the Calendar's day line counts those tasks as "planned" and "booked" with its events listed apart ("5 planned · 2 h 30 min booked · 3 events"). The menu's Today row counts tasks scheduled today as well as due today, and its Calendar row no longer says "Free · Nothing else today" while a timed task is still ahead.
- Minutes of a task with a time but no estimate now count as 30 (the length the Calendar draws it at) in the day's focus total, the time-left card, the Calendar's "booked" and, on desktop Home, the minutes left today. A day plan pick that the evening close sent to tomorrow or Someday, or that now sits on a later day, no longer counts as today's task. With Hide done on, the Calendar's day line says how many done tasks it holds back ("2 done hidden").
