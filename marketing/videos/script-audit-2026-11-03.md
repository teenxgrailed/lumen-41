# H1–H3 voice scripts: audit against content-principles (2026-11-03)

The test for each script is whether line 1 sells line 2. Below is the weakest seam in each script and a replacement for it. Nothing in the specs has changed yet. If a replacement is accepted, edit `lines` in that video's `audio-spec.json` before Needt Cloud generates the audio.

## H1 "Feed it all in"

Weakest line: 0.8 "Tabs. Mail. Code. Calls."

- It lists categories, so the viewer has nothing to be curious about.
- About 3 s of picture follow before "Feed it all in." In that time the viewer holds no question, so line 2 doesn't feel needed.

Replacement for vo1 (0.8–3.4, still under the chaos):

> "Tabs. Mail. Code. Calls. Who's on all of it?"

- This opens the loop that "Your agents pick it up." / "You just say yes." pays off.
- At the voice's slow pace the line takes about 2.8 s. Check that it ends before 3.6.

## H2 "It plans the day"

Weakest line: 7.4 "Your week. Sorted."

- It closes the only open loop with 6.6 s still to go, so the viewer feels done and scrolls before the "now" line runs.
- "Sorted" is a summary, not something you can see.

Replacement for the line at 7.4:

> "All nine placed. Now watch today."

- The number 9 is in the picture, so no number is made up.
- It opens a new loop over the "now" line (7.9–9.9). "You just show up." pays it off at 11.35.

## H3 "Everything in one place"

Weakest line: 1.1 "Calendars. Mail. Docs. Habits."

- Like H1, it lists categories, and "It all syncs in." then answers a question nobody asked.
- Both videos also open with the same four-noun list, so they read as one template.

Replacement for the line at 1.1:

> "Four places. Which one did you write it in?"

- It names a pain the viewer knows (where did I put it).
- The loop stays open until "…it's everywhere." at 8.7. That is the payoff of the whole video.
