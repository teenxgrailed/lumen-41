## Decisions and constraints

- The face switch is in `phone/places/Faces.tsx` and the pages render it (as P7 does for Docs); desktop screens are still the exported desktop faces, now fed by the controller.
- Pending-write guards live in the controllers (refs), not in `isPending`, because `isPending` only changes on the next render and a second face has its own hook instance of the mutation.
- Disconnect closes the account sheet after the write returns, whether it succeeded or not (a failure shows the error notice); no Undo, as on the desktop.
- Connect leaves the page for the provider's consent screen; the row shows "Connecting" until the page unloads (desktop behaviour).
- The Connected / All split of the desktop is one chip in the phone strip ("All" is pressed only when neither it nor a category narrows the list), so a filter set on one face is visible on the other.
