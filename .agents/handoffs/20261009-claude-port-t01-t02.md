## Contract notes for S2–S4 (read before porting)

- The scope element is the prototype's `<html>`: it carries
  `data-theme="light|dark"`, `data-drift="on"` (Time), `data-accent`.
  Theme classes in a selector's first compound moved onto it:
  `.app.dark` → `.needt-v3[data-theme="dark"] .app`. So the shell's `.app`
  div keeps `app theme-surface theme-drifts` but **no theme class**.
- `html.is-drag-active` / `html.is-pd-drag` became `.needt-v3.is-…`: drag
  code toggles the class on the scope element (closest `.needt-v3`), not
  on `document.documentElement`.
- Every `@keyframes` is renamed `v3-<name>` (46 collided with v2). Inline
  `animation:` strings in components must use the `v3-` name.
- A theme miniature re-themes by nesting `<div className="needt-v3"
data-theme="dark">`.
- Display face: `var(--font-v3-exposure)`; doc fonts `--font-v3-serif`
  (Newsreader), `--font-v3-rounded` (Nunito).
- Providers/QueryClient are the root layout's (shared); v3 keys stay
  `["v3", …]`. `useDesignV3()` is the client-side flag.
- Theme/accent live in `useNeedt3Ui` (mirrored to localStorage); T21 must
  persist them to `UserSettings` and call `setLook`.
