## Completed

- `src/lib/needt3/phone-ui.ts` (+ Jest): `phoneUiFrom({ secChUaMobile, userAgent, cookie })`, `resolvePhoneUi`. `(app)/layout.tsx` reads `headers()` / `cookies()` only inside the flag-on branch and passes `initialUi` / `uiForced` to `<V3Root>`.
- One stable tree: `root/ShellFrame.tsx` is the single skeleton of the frame (root element -> portal scope -> row -> one `<main>` -> keyed stage). `V3Shell` fills three chrome slots (`top`, `rail`, `overlays`) per `ui`; the children never move. Jest (jsdom) mounts it, flips `ui` both ways and asserts same `<main>` and page nodes, one mount, zero unmounts, a typed value kept. `useResolvedPhoneUi`: server pick on the first render, `matchMedia('(max-width: 699.98px)')` read in a layout effect, a pinned cookie wins. `usePhoneUi()` tells a screen which layout to draw.
- Menu A (`phone/menu/*`): pill that grows into the card (clip-path shape), three places + dot grid, create button, hold-the-pill to capture, tiles on the CSS sky band, rows with what is waiting (`status.ts`, `counts.ts`, read from the same hooks as the rail), fog, head, handle, tuck hint, rubber band, flick snap (`nvaRelease`), Escape, reduced motion. Pure logic with Jest: `src/lib/needt3/menu-a.ts` (geometry, track, snap, frame), `menu-shadow.ts` (nine-slice shadow).
- Phone shell (`phone/shell/PhoneShell.tsx`): wires the places to routes (`PLACES` in shell/places.ts, Connections = `/connections`), Ask = `setAskOpen(true)`, composer = `setComposerOpen(true)`, Settings / account row = `openSettings()`, the one-shot `pkDotSweep` on a place switch, `usePhoneCover(open)` for a place's full-screen layer (menu steps aside), renders `<PhoneOverlays />`.
- P3 contract: `data-nva-pill` on `.nva-glass` (its box is the closed pill; radius = computed style); the plus on the pill and Ask call the store; `phone/overlays/PhoneOverlays.tsx` is the stub P3 replaces.
- Rule 12: transform / opacity / clip-path only per frame; ground opacity written directly (no custom property per frame); shadow = static nine-slice pieces moved by transform; one rAF per pointer stream (`frameWriter`); springs from `spring.ts` via refs; one ResizeObserver; exactly one backdrop-filter while moving (the pill's glass): fog, head, tiles and the create button lose theirs, and `[data-v2p-host][data-nva-moving]` drops the screen's (P2 section in motion.css); no loop at rest (fog drift animation removed when the fog is hidden).
- CSS: the phone sheets come from the generated `v3/index.css` (after the s1-p1 merge); `src/styles/v3-phone.css` and its import are gone, so nothing loads twice. Order: `v3/index.css` -> `v3-overrides/motion.css` -> `v3-overrides/type.css` -> the rest. Hand-written rules under the P2 header in `v3-overrides/motion.css`.
