# Open-source идеи для Needt — ресёрч

_2026-10-21 · ~230 репозиториев и страниц · 13 агентов в 2 раунда, второй раунд — перепроверка + 4 новые сферы · глубина: deep_

**Перепроверено:** все 90 GitHub-репозиториев из первого раунда существуют; ни один не архивирован и не переименован; звёзды в пределах ±10 %, даты совпадают. Исправлены 4 лицензии и одна ошибка про Furlough. Платформенные утверждения сверены с документацией Apple и Chrome, см. раздел «Платформы: что можно и что нельзя».

Звёзды, лицензии и дата последнего push — из GitHub REST API на 2026-10-21. Описание фич — из README;
где агент брал из своих знаний, а не из README, стоит пометка _(не проверено)_.

**Лицензии.** Код можно брать только из MIT / Apache-2.0 / BSD / MPL-2.0 / EPL-2.0. GPL и AGPL —
только идеи. Source-available (n8n, Outline BSL, Anytype, Open WebUI, Open Sunsama) — только идеи.

## Коротко

1. **Фокус-блок в календаре сам включает профиль блокировки** (сайты + приложения + уведомления + жёсткость
   разблокировки). Ни у одного open-source блокировщика нет календаря — у Needt он уже есть. Это главное
   незанятое место во всей выборке. Источники: Focuser, Foqos, Furlough, FocusGate.
2. **Island = типизированный канал live-активностей, который наполняется через API/MCP.** У boring.notch
   (11.1k★) «extension system» до сих пор не сделан. Needt может первым дать внешним инструментам
   пушить активности в нотч. Источники: Atoll, boring.notch, SketchyBar, MeetingBar.
3. **Агент: план → превью изменения → клик → проверка результата**, разрешения allow-once/session/always,
   история решений без содержимого. Источники: Yumi (нотч-агент), Nanobrowser (расширение).
4. **Правила на простом языке с прогоном на прошлых данных** («рассылки → задача "прочитать"», с показом,
   что совпало бы из последних 50 писем). Укладывается в read-only почту. Источник: Inbox Zero.
5. **Сила привычки вместо стрика** — экспоненциально сглаженный счёт, один пропуск не обнуляет месяцы.
   Дёшево, сразу видно. Источник: Loop Habit Tracker.
6. **Расширение для Chrome: выделил текст → Alt+Shift+N → задача с URL-источником, сразу авто-планируется.**
   Плюс быстрый ввод с разбором «завтра 2ч #work !high». Источники: vikunja-webextension, Todoist.
7. **Встреча = заметка, без бота.** В island кнопка «Войти и записать»: открывается ссылка звонка, идёт запись,
   заметка привязана к событию. После встречи action items становятся задачами, которые сразу планируются.
   Ни один open-source ноутейкер не пишет задачи в планировщик. Источники: anarlog (ex-Hyprnote), OpenWhispr.
8. **Ритуал закрытия дня и недельный обзор.** Незавершённое переносится на завтра, показано «запланировано
   против доступного»; недельный обзор сохраняется как Page. Источники: tududi, Open Sunsama, Sunsama.
9. **Платформенные ограничения, важные для Pro и MAS.** App Review Guideline 4.10 запрещает монетизировать
   Screen Time API. Screen Time API на macOS нет. Mac App Store не даёт закрывать чужие приложения. Значит,
   блокировка в MAS-версии возможна только через Network Extension, а на iOS её нельзя прямо брать за деньги.

## Осталось неясным

- **Content filter в MAS.** TN3134 его допускает, но прямого заявления Apple, что system extension проходит
  MAS-ревью, нет, и нет ни одного MAS-блокировщика с известным механизмом. Ответ даст только тестовая отправка.
- **Как Guideline 4.10 применяется к подписке**, где блокировка — одна из функций Pro, а не единственная. Нужен
  вопрос в App Review.
- Screen Time на macOS 27 — release notes не проверены; по докам на 2026-10 его нет.
- Можно ли вызывать Foundation Models из Safari-расширения через native handler — не задокументировано.
- Zero и Prisma: совместимость схемы не проверена; CP-SAT лучше `SlotScorer` — гипотеза без бенчмарка.
- У Meetily пробелы (нет календаря и чата) взяты со страницы конкурента OpenWhispr.
- Лицензия Tab Manager Plus не прочитана. Звёзды не проверены у Focalboard и TimeLimit (Codeberg).
- Фичи, помеченные _(не проверено)_, взяты из знаний агентов, а не из README: n8n, Windmill, Home Assistant,
  Open WebUI, LibreChat, LeechBlock (детали), Anytype, AppFlowy, Plane, Leantime.
- Работает ли Vicinae на macOS и насколько формат Raycast-расширений реально совместим — не проверено.
- Open-source «один sec»/«Opal»/«Brick» на iOS полноценного уровня нет; ближайшие — Foqos и Furlough.
- **SlopBlocker на iOS:** влезет ли модель ~65 MB в процесс Safari-расширения на iPhone и доступен ли WebGPU
  в контексте расширения (а не страницы) — не проверено, нужен тест на устройстве. Скорость и расход батареи
  при вызове Foundation Models через native messaging — не проверены.
- Какую модель использует SlopBlocker.ai и как он классифицирует — неизвестно (закрытый).
