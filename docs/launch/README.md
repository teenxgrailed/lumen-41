## Rules applied

- `content-principles`: the hook is an event, the object is specific, short lines.
- Brand only: no founder name. "Made by one person" is used because the landing says it.
- No company is named as a partner. Claude, ChatGPT, Cursor and others appear only as tools
  Needt connects to, as on the landing's Integrations section.
- Agents: "free to start", never "free for everyone".
- Not claimed, because the sources disagree or it is not live yet:
  - Mac and iPhone apps (the landing says "Coming");
  - two-way Google Tasks (the landing shows ⇄, the changelog says the import is one way);
  - bring-your-own AI key on Free (the landing says so, but Terms say Free has no assistant);
  - Gmail for everyone (the Google scope review is failing, see launch-readiness);
  - the student price (the landing says "Coming soon");
  - the Chrome extension (not in the Web Store yet).
