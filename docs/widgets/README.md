# Виджет Needt для iPhone (Scriptable)

Личный виджет: сколько задач осталось, следующая задача со временем в виде точечного LED-дисплея, привычки, ближайшее событие, окно личного времени, свободное время и погода. Токен хранится в Keychain Scriptable, в коде его нет.

Данные берутся одним запросом: `GET /api/connect/today`.

## 1. Установить Scriptable

App Store, приложение Scriptable (бесплатное).

## 2. Создать токен в Needt

1. Открой `https://use.needt.app/connections`, вкладка AI tools.
2. Плитка Needt API, шаг 1, Create an access token. Токен вида `needt_...` показывается один раз, скопируй его сразу.
3. Повторная генерация отключает старый токен: все агенты и виджет придётся перенастроить.

Тот же токен хранится в Settings, Personal API.

## 3. Добавить скрипт

1. В Scriptable нажми `+`, новый скрипт.
2. Вставь весь код из `docs/widgets/needt-widget.js`.
3. Назови скрипт `Needt`.
4. Запусти его (треугольник). При первом запуске появится окно, вставь токен, Save.
5. Откроется меню: Preview small / medium / large. Проверь, что данные пришли.

Сменить токен: запусти скрипт в приложении, пункт Change token.

## 4. Поставить виджет

Домашний экран:

1. Долгое нажатие на экран, `+`, Scriptable, размер (small, medium, large), Add Widget.
2. Нажми на виджет, Edit Widget, Script: `Needt`. Остальное оставь по умолчанию (When Interacting: Open App не нужен).

Экран блокировки:

1. Долгое нажатие на экран блокировки, Customize, Lock Screen, область под часами или над ней.
2. `+`, Scriptable, нужный тип: прямоугольный, круглый или строка. Нажми на виджет, Script: `Needt`.

## Что показывает каждый размер

| Размер           | Содержимое                                                                                                                                                                     |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| small            | Фраза "N left today", время следующей задачи в точечном дисплее                                                                                                                |
| medium           | Слева highlight дня (или следующая задача) и пилюля со временем. Справа карточка: пилюли привычек (эмодзи, галочка, неделя 2/3) и тонкая полоса свободного времени             |
| large            | Фраза с числом оставшихся, точечное время следующей задачи, до 5 задач со временем, привычки, ближайшее событие, окно личного времени ("Lunch 13:00"), свободное время, погода |
| экран блокировки | Прямоугольный: следующая задача и время. Круглый: кольцо done/total. Строка: "Next · 11:00 Название"                                                                           |

Цвета: тёмный фон `#141416` (в светлой теме бумажный), серые это один цвет текста с разной прозрачностью, лавандовый только для "сейчас", прогресса и выбора, зелёный только для выполненного.

## Нажатия

- Нажатие на виджет открывает `https://use.needt.app/today`.
- В medium и large нажатие на строку задачи открывает её: `/tasks?task=ID` (приложение читает этот параметр).

## Обновление и офлайн

Обновление примерно раз в 15 минут (iOS сам решает, когда). Без сети виджет показывает последние данные с пометкой `offline` и временем. Следующая задача пересчитывается при каждой отрисовке, даже из кэша.

## Какой токен нужен и что читается

| Данные                                                                                            | Откуда                                  |
| ------------------------------------------------------------------------------------------------- | --------------------------------------- |
| Всё сразу: счётчики, задачи, highlight, привычки, событие, личное время, свободные минуты, погода | `GET /api/connect/today` (`needt.read`) |

День считается в часовом поясе из Settings, а не в поясе телефона или сервера. Погода есть, если в Settings задан City. События приходят только из личного workspace. Описание полей: `docs/connector-api.md`, раздел "Widgets: today, highlight, habits".

Отдельные запросы для своих виджетов: `GET /api/connect/highlight`, `GET /api/connect/habits/today`, `POST /api/connect/habits/ID/toggle-today` (последний нужен будущему интерактивному виджету, текущий виджет его не вызывает).

## Если /api/connect/today ещё не выкатили

Если сервер отвечает 404, виджет сам переходит на старые запросы: `GET /api/connect/tasks` и `POST /api/mcp` (`needt_list`: event, habit). В этом режиме нет highlight, точного состояния привычек (галочки и счётчик недели скрыты), свободного времени, личного времени и погоды. Ошибка токена (401/403) и сетевые ошибки в этот режим не переключают: показывается кэш или сообщение.

## Проверка

Синтаксис проверен `node --check` (код обёрнут в async-функцию), раскладка прогнана на заглушках глобальных объектов Scriptable для всех размеров, фолбэка, офлайна, пустого дня и ошибки токена. В самом Scriptable и на iPhone виджет не запускался: реальный вид и высоты блоков не проверены.
