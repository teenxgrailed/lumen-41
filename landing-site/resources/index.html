Ideas

Some ideas to get you started.

Small workflows that save a few minutes every day. Each one takes about two minutes to set up.

Morning brief

Ask Claude for the day before you open anything else. It reads your schedule, flags what slipped and suggests the first block.

Inbox to plan

Paste a messy email thread into ChatGPT. The asks become tasks with estimates and deadlines, placed into free time.

Set up with MCP

TODOs from your code

Working in the terminal? Claude Code turns the TODOs in a branch into tasks under your project, without leaving the repo.
