Web

Any browser, nothing to install. Works on a computer that isn’t yours.

Mac

Its own window and a Dock icon, installed from the browser.

  1. Open use.needt.app in Chrome or Edge.
  2. Click the install icon in the address bar.
  3. In Safari: File → Add to Dock.
Open Needt

Windows

Lands in the Start menu like any other app.

  1. Open use.needt.app in Edge or Chrome.
  2. Click the install icon in the address bar, or ⋯ → Apps → Install.
Open Needt

iPhone and iPad

Home Screen icon, full screen, notifications.

  1. Open use.needt.app in Safari.
  2. Tap Share → Add to Home Screen.
  3. Open Needt from the new icon.

Android

An app icon and full-screen window from Chrome.

  1. Open use.needt.app in Chrome.
  2. Tap ⋮ → Install app (or Add to Home screen).
